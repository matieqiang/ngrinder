gradle structure introduce
===

## structure
```
└── <project folder>
    └── gradlew
    └── gradlew.bat
    └── gradle
        └── wrapper
            └── gradle-wrapper.jar
            └── gradle-wrapper.properties
    └── build.gradle
    └── gradle.properties
    └── settings.gradle
```

see: https://docs.gradle.org/6.9.1/samples/sample_building_spring_boot_web_applications.html
see: https://spring.io.zh.xy2401.com/guides/gs/gradle/
